Mon Premier test avec Github POUR COMPRNDRE LES CONEPTS DE BASE, que je partage pour avis, suggestions et/ou commentaires:
Repository (Repo) : 
	Un dépôt est comme un dossier où l'on stocke tous les fichiers et l'historique de version d'un projet. 
	Chaque dépôt a une copie locale sur l'ordinateur du développeur et une copie distante sur GitHub.

Commit : 
	Un commit est un instantané du code à un moment donné. 
	Il permet de sauvegarder l'état des fichiers et de revenir à une version antérieure si nécessaire.

Branch : 
	Une branche est une version parallèle du code. 
	Par défaut, le dépôt commence par la branche "main" ou "master". 
	Les développeurs créent souvent des branches pour travailler sur des 
	fonctionnalités ou des corrections de bugs séparément.

Pull Request : 
	Une pull request est une demande 
	pour fusionner des modifications d'une branche dans une autre, 
	souvent de la branche de développement vers la branche principale. 
	C'est l'étape où les contributions sont examinées et validées avant d'être intégrées.

Fork : 
	Un fork est une copie du dépôt 
	d'un autre utilisateur sur votre compte GitHub. 
	Il permet de modifier le code sans affecter l'original.

Issues : 
	Les issues sont des tickets utilisés pour suivre 
	les bugs, les demandes de fonctionnalités, ou toute autre tâche dans un projet.

GitHub est largement utilisé pour 
collaborer sur des projets open source, 
mais aussi dans le développement en entreprise pour faciliter le travail en équipe.
